PÁGINA PARA ALONDRA ♡

PARA VERLA EN TU COMPUTADORA:
1. Descomprime pagina_alondra.zip.
2. Abre la carpeta y haz doble clic en index.html.

PARA PERSONALIZARLA:
- Mensaje y nombre: abre index.html con un editor de texto y busca el texto que quieras cambiar.
- Fecha de aniversario: abre script.js y cambia:
  const anniversaryDate = "AAAA-MM-DD";
  por la fecha real, por ejemplo:
  const anniversaryDate = "2025-04-12";
- Fotos: coloca tus fotos en la carpeta images con estos nombres:
  foto1.jpg, foto2.jpg, foto3.jpg, foto4.jpg

PUBLICAR GRATIS CON GITHUB PAGES:
1. Crea una cuenta en https://github.com (si no tienes).
2. Crea un repositorio nuevo llamado alondra-mi-bebe (puede ser público).
3. Pulsa Add file > Upload files y sube index.html, style.css, script.js y la carpeta images.
4. Entra a Settings > Pages.
5. En "Build and deployment", selecciona "Deploy from a branch".
6. Selecciona la rama "main" y la carpeta "/ (root)", y pulsa Save.
7. Espera unos minutos. GitHub mostrará un enlace parecido a:
   https://TU-USUARIO.github.io/alondra-mi-bebe/
8. Abre ese enlace para comprobarlo y mándaselo a Alondra por WhatsApp.

IMPORTANTE:
- Sube los archivos, no solamente el ZIP.
- El contador no mostrará días hasta que cambies la fecha en script.js.
- La música no está activada por defecto para que la página no reproduzca audio sin permiso. Si quieres, puedes añadir un enlace o un archivo de música después.
- No necesitas compartir contraseñas con nadie.
